# Electricity Consumption AI

An AI-powered app to track, predict, and manage electricity consumption. 
Sends WhatsApp and email alerts based on usage patterns.

## Features
- User login & registration
- AI-based bill/usage prediction
- WhatsApp & Email alerts
- Dashboard with bill history & charts
- Tips to reduce electricity usage

## Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Python
